# 自测工具（静态分析 + 动态遍历）

改完代码后**跑一遍这两个方向**，是发现"崩溃 / 功能失灵 / 逻辑错误"最有效的方式。
上次那个"打开 Edge 就崩溃退出、日志还空白"的问题，就是动态遍历抓出来的。

## 怎么跑

**最简单**：双击项目根目录的 **`自测.bat`**，报告会输出到 `tests\自测报告.txt`。

**单独跑某一项**：

```powershell
python tests\check_static.py     # 静态分析
python tests\check_dynamic.py    # 动态遍历压测
python tests\check_startup.py    # 启动性能 + 启动瞬间朝向
python tests\check_sound.py      # 音效系统
```

## 各项检查什么

| 脚本 | 覆盖内容 |
|---|---|
| `check_static.py` | ① 语法编译 ② **pyflakes**（未定义变量、重复定义、未使用变量）③ **AST 扫描**（注释里被吞掉的赋值语句、函数内未定义变量、超长函数提示）。不需要 Qt，纯文本分析 |
| `check_dynamic.py` | 遍历面板**每一个按钮/复选框/滑块/下拉/输入框/列表项**，再模拟日常操作：连点、长按、拖拽、右键、弹射（含边缘反弹）、喂食文件与目录、跟随/躲避/漫游/锁定/置顶五种模式 tick、表情与大小全量切换、台词与气泡全量切换、音效播放、应用监控触发、日志清理。**任何被异常保护记录的异常都会打印出来** |
| `check_startup.py` | 启动分段耗时（扫描/初始化/首帧）、启动到可见总时间、**启动瞬间朝向**（贴左边缘应立即镜像、右侧不镜像）、音效延迟预加载是否生效、启动耗时是否写入日志 |
| `check_sound.py` | 音效目录扫描、播放器池"每声完整播放"、池满接管最早、预加载不重复、自定义音效覆盖点击/松手、音量同步 |

## 结果怎么看

- `[OK]` / `ALL OK`：通过
- `[WARN] n 条`：需要人工判断（例如 AST 的"超长函数"提示属于可维护性建议）
- `发现异常（应修复）` + 堆栈：**必须修复**，那是真实 bug
- 末尾 `进程存活: True`：说明整个过程没有把程序搞崩

## 为什么这两条路都要走

- **静态分析**能发现"代码根本没被执行到"的问题：未定义变量、写错的属性名、被注释吞掉的语句（上次崩溃的元凶）
- **动态遍历**能发现"代码跑起来才炸"的问题：Qt 参数不匹配、空数据、状态组合、弹窗回调……
  两条路互补，缺一个都会漏。
